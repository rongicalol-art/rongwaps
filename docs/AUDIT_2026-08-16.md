## 2. Security

### HIGH

- **`mnemonic_generation_queue` is effectively world-writable** — `supabase/migrations/20260606100100_memory_hooks.sql:30-38`. The comment says "Only service role / backend can modify", but the policies are `INSERT ... WITH CHECK (true)` and `UPDATE ... USING (true) WITH CHECK (true)`, with no role restriction. Anonymous clients can insert and rewrite any queue row.
- **`user_profiles` exposes PII to anonymous clients** — `supabase/migrations/20260606_auth_profiles.sql:17-19`. `SELECT ... USING (true)` means any anonymous request can read every user's `email`, `full_name`, and `avatar_url`. The comment cites "community features", but no such feature exists yet.

### MEDIUM

- **Global `mnemonics` cache poisonable by any authenticated user** — `supabase/migrations/20260527_user_data.sql:106-112`. INSERT (`auth.role() = 'authenticated'`) and DELETE (`auth.role() = 'authenticated'`) let any logged-in user inject or delete arbitrary mnemonic content (cache poisoning / denial).
- **Anonymous storage writes + overwrites on the public TTS bucket** — `supabase/migrations/20260804_tts_cache_policies.sql:7-26`. `anon` is granted INSERT **and UPDATE** on `storage.objects` under `tts/` in the public `vocabulary-audio` bucket. An attacker can overwrite cached audio files.
- **`/api/tts` POST is unauthenticated** — `server.ts:147`. Any anonymous client can synthesize up to 10/min (per-IP rate limit, bypassable) using a paid neural TTS service. The `/api/audio/*` and `/api/tts*` GET routes are likewise unauthenticated (fine for audio streaming, but the write/synthesize path should require auth).
- **Stale security comment** — `server.ts:129-131` states "upsert requires an UPDATE policy that anon lacks", but `20260804_tts_cache_policies.sql` now grants anon UPDATE. The comment no longer reflects the DB.

### LOW

- **Service-role client lives in the app tree** — `src/features/character-decomposition/staging/supabaseStaging.ts:121` (`createDecompositionStagingClient`) accepts a service-role key and is barrel-exported under `src/features/`. It is currently imported only by scripts (`stageDecompositionSources.ts`, `buildDecompositionRuntimePacks.ts`), but placing it under `src/` makes it trivial to accidentally ship the service-role key to the browser. Recommend moving to `scripts/` + adding a `process.env` / browser guard.
- **`handle_new_user()` is `SECURITY DEFINER` without `SET search_path`** — `supabase/migrations/20260606_auth_profiles.sql:35`. Minor hardening opportunity.
- **Tracked config file that looks like secrets** — `scripts/.config.json` is git-tracked and contains a real Supabase URL plus placeholder key slots (`GEM...`, `eyJ...`, `sk-o...c`). Recommend `git rm --cached` + gitignore.
- **`ids.txt` (2.1 MB) tracked despite `.gitignore`** — the ignore rule lists `ids.txt` but it was committed before the rule. `git rm --cached` to honor it.

### Verified good

- `.env` is gitignored; only `.env.example` is tracked. No hardcoded keys in `src/`.
- No screen/widget imports Supabase/fetch/Axios directly (the one hit in `DebugWindow.tsx` is just a dashboard URL string).

## 8. Recommendations for the build pass (top fixes, ordered)

1. **RLS hardening (new migration, do not edit applied ones):** restrict `mnemonic_generation_queue` to `auth.role() = 'service_role'`; restrict `user_profiles` SELECT to authenticated (or self-only); restrict `mnemonics` DELETE/INSERT to service role.
2. **Storage:** drop anon UPDATE on the TTS bucket (keep INSERT or route writes through the authenticated server client).
3. **Add auth** to `POST /api/tts`.
4. **Accessibility:** add `role="button"`/`tabIndex`/keyboard handlers to the four `<div onClick>` cards; add `aria-label` to the two icon-only buttons; label the three form inputs; add `useModalFocus`/Escape to the three library modals.
5. **Bundle:** lazy-load / split `interactiveGrammarPages` and the main chunk; convert hero images to WebP/AVIF.
6. **`prefers-reduced-motion`** gating for `anim-*` and `.spring-transition`.
7. **Scrollers:** consolidate the per-screen `overflow-y-auto` containers back into the shell scroll.
8. **Docs/widgets:** document `PartProgressRail` + `ExpandableSearch` in `WIDGETS.md` and the barrel; fix `PlayfulNavIcon` union; route `react-icons/pi` through `AppIcon`.
9. **Housekeeping:** remove `scripts/.config.json`, `git rm --cached ids.txt`, delete orphaned scripts + `worker/index.js`, fix the stale `server.ts` TTS comment.
