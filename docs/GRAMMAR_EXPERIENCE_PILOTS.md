# Source-First Grammar Lessons

The Learn view follows the source book closely, then simplifies its grammar for beginners. Lessons 10, 12, and 13 are the visual and teaching benchmark: calm, short, book-aligned, and interactive only when an interaction makes the rule easier to understand.

## Lesson structure

All 68 grammar pages across Lessons 1–14 use the same clear reading order:

1. Book-aligned title, printed page, and concise explanation.
2. Source sentence pattern.
3. Source examples.
4. One collapsed **Interactive help** line after the book material.
5. When opened, one short authored teaching tool plus any useful mistake or contrast.
6. Existing Practice mode.

The source reading, grammar meaning, printed page, patterns, examples, and practice data remain preserved. Added teaching text should clarify the source, not compete with it.

Each grammar title includes a quiet **View book page** action. It opens the exact referenced printed page or pages exported from the source lesson PDFs. Regenerate these learner-safe page assets with `npm run book-pages:export`.

## Teaching standard

Each Learn page should:

1. Explain one idea at a time in plain international English.
2. Keep Chinese primary, with optional pinyin and English support.
3. Use short labels and examples instead of long instructions.
4. Make word order or meaning visible when that genuinely helps.
5. Include one useful interaction at most; keep it collapsed by default and never add interaction only for decoration.
6. Preserve contextual dictionary access for teaching words and phrases.
7. Keep visual decoration quiet so the book rule remains the focus.
8. Avoid custom “teaching worlds,” story wrappers, and illustrations unless the grammar cannot be explained clearly without them.
