## Exercises: the book's items only, in book order, `source` on every item

No extra items this round, but every book item must be present.

| Book item | Author as |
|---|---|
| 練習1 phrase-bank item | One `reply-pick`. `lines` = A's line, then B's line with its printed start + one `slot` + the printed end. `fill` = the pattern (with pinyin). `options` = the book's bank cards verbatim, with ～ kept. Mark `ok` on every card that fits this item (the book allows several). Each ok card gets a `result` (full B line, pinyin, English); each wrong card gets a one-line `note` naming why it doesn't fit (e.g. "This card is about one event (一次); A is describing a person."). |
| 練習1 "answer yourself" item | Two items. **First** a `reply-pick`: the same `lines`, with 3 replies you write. One is right; two are typical misuses of this point (wrong word order, missing part of the pattern, the wrong sense). **Then** an `order-build`: `sub` = A's line, `prompt` "Now say it yourself.", building the right reply's pattern clause (≤6 tiles, ≤4 characters each, one trap tile with a `placed` repair). |
| 練習1 fill-in, no bank | One `order-build`. `sub` = A's line; B's printed start goes in `lead` if the engine has it, else in `sub` after A's line. The learner builds the completion with the pattern. Keep grammar-bearing words as separate tiles. List natural equivalents in `accepted` (e.g. 也/都 both right where the book allows both). |
| 練習2 situation | Two items. **First** a `reply-pick` with `situation` = the book's situation (Chinese verbatim, `english` = a plain translation) and 3 replies (one right, two typical misuses). **Then** an `order-build` with the same `situation`, `prompt` "Now say it yourself.", building the right reply's pattern clause. |

Rules:
- **Taught words only:** Book 1, Book 2, Book 3 Lesson 1 Part 1/2 vocabulary up to the page's part, plus Book 3 grammar examples so far. Book-printed words go in `allowWords`. The extended test (`B3_REDONE` includes 1) must pass.
- **One right answer** in every `order-build` and every situation `reply-pick`; phrase banks may have several right cards, exactly as the book allows. Decide which cards fit from the item's context; if the book's intent is unclear, write it under Unsure.
- Titles follow the exercise prompt rule: a short English instruction ("Complete B's reply with 可以說是.", "What do you say?"). No English translation of the answer before answering. `sub` says "More than one card may fit." on bank items.
- Every wrong option and every trap tile explains itself in one plain sentence.
- Pinyin: the book's tones, 一/不 sandhi, neutral tones as printed.
- Replace all existing L1 practice items. None of the old invented items stays.
